# Introduction to SPSS

This course, **Introduction to SPSS**, is organized by the **Comilla University Research Society** as a **3-day SPSS training module**.

## Course Overview

The module is designed to introduce participants to IBM SPSS and build practical skills in data entry, cleaning, analysis, visualization, and interpretation of results.

## 3-Day SPSS Training Module

### Day 1: SPSS Basics and Data Handling

- Introduction to SPSS
- What is SPSS?
- SPSS interface overview
- Data View vs Variable View
- Variable setup
- Variable types: numeric, string
- Label, value labels, missing values
- Measurement scale: nominal, ordinal, scale
- Data entry and cleaning
- Data input
- Handling missing values
- Recode: same variable and different variable
- Basic descriptive statistics
- Frequency
- Mean, median, mode
- Standard deviation

### Day 2: Data Analysis and Visualization

- Data transformation
- Compute Variable
- Advanced Recode
- Cross-tabulation
- Categorical data analysis
- Graphs and visualization
- Bar chart
- Pie chart
- Histogram
- Explore function
- Normality check
- Outlier detection
- Correlation and regression analysis
- Correlation analysis
- Pearson correlation
- Simple and multiple correlation
- Regression analysis
- Simple linear regression
- Multiple regression
- Logistic regression
- Interpretation of relationships

### Day 3: Statistical Tests and Report Writing

- Hypothesis testing basics
- Null vs alternative hypothesis
- p-value concept
- T-Test
- One-sample t-test
- Independent sample t-test
- ANOVA: basic introduction
- One-way ANOVA
- Chi-square test
- For categorical variables
- Reliability test
- Cronbach's Alpha for Likert scale data
- Report writing from SPSS output
- Interpreting results
- Using tables and graphs in research

## Learning Outcome

By the end of the course, participants should be able to enter, clean, analyze, visualize, and interpret data in SPSS for basic research and academic reporting.
